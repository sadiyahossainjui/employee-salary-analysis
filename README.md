# 📊 Employee Salary Analysis

## 📌 Project Overview
This is a beginner-friendly data analysis project using Python and Pandas.  
The goal of this project is to clean employee data and perform salary analysis to generate useful business insights.

---

## 🛠️ Tools Used
- Python
- Pandas
- CSV
- GitHub

---

## 📂 Dataset
The dataset includes:
- Employee Name
- Department
- Salary
- Join Date

---

## 🔍 Key Steps Performed

### 1. Data Cleaning
- Handled missing salary values using average salary
- Replaced missing department with "Unknown"
- Removed duplicate records

### 2. Data Processing
- Converted Join Date to datetime format
- Extracted Year from date

### 3. Data Analysis
- Calculated average salary by department
- Counted number of employees per department
- Identified highest paid employee

---

## 📈 Sample Insights
- IT department has the highest average salary
- Missing values were handled to ensure accurate analysis
- Duplicate records were removed to avoid bias
